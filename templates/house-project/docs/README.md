# Documentation map

| Subject                              | Canonical owner                              | Activation rule                                      |
|--------------------------------------|----------------------------------------------|------------------------------------------------------|
| Property scope and entity references | [property.md](property.md)                   | Update when documented facts or entity links change. |
| Durable decisions                    | [decisions/](decisions/README.md)            | Add an ADR only for a real durable decision.         |
| Provenance, privacy, and certainty   | [../sources/README.md](../sources/README.md) | Update with each source-backed fact or restriction.  |
| Generated exports                    | `../exports/`                                | Never treat exports as canonical source.             |

Do not create projects, maintenance, systems, research, or long-running-work directories until there is real material
with an identified owner. Add their routing entries here at activation time.
