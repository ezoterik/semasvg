# Architecture decisions

This category is initially empty. [`0000-template.md`](0000-template.md) is an authoring aid and does not activate the
category. Copy and rename it to `0001-short-title.md` for the first real durable decision. Name later files sequentially
as `NNNN-short-title.md` and keep numbers stable.

Use one status:

- proposed: under consideration and not yet adopted;
- accepted: adopted for the project;
- superseded: fully replaced by a later ADR;
- rejected: considered and not adopted.

For total supersession, the superseded ADR must link to its replacement, and the replacement must link back to every ADR
it supersedes.

This README defines the routing and naming rules for future ADRs.
