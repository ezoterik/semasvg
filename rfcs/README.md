# RFC index

RFCs are non-normative design and rationale records. Specifications and their machine-readable owners remain
authoritative.

## Numbering and lifecycle

RFCs use stable four-digit numbers. `0000` is reserved for the template. Do not renumber, reuse, or recycle a number.

An RFC is `Draft`, `Accepted for <version>`, `Rejected`, or `Superseded`. A superseding RFC and the RFC it supersedes
must link to each other.
